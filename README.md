# Lista Madagascar — CRSI

Site da Lista Madagascar do Colégio Rainha Santa Isabel.

## Conteúdo atualizado
- Logo original da Lista Madagascar incluído em `public/logo-madagascar.png`
- Paleta verde, laranja, amarelo e roxo inspirada no logo
- 30 elementos da lista
- 18 projetos
- Sunsets mensais
- Conferências durante o ano
- Palestras mensais
- Eventos e calendário recorrente

## Deploy Netlify
Build command: `npm run build`
Publish directory: `dist`

## Para atualizar o site existente
Substitui os ficheiros do repositório GitHub por esta versão e faz commit. O Netlify fará novo deploy mantendo o mesmo URL.
